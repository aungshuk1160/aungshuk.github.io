📱 USSD Simulation System

USSD Simulator for Feature Phones and Mobile Networks

A practical USSD simulation platform built to emulate real-world feature phone interactions and USSD workflows. Users can send, receive and test USSD menus & responses in a web-based environment. Ideal for developing and testing telecom applications before deployment.

🌟 Key Features

  • Simulated USSD session flows
  • Interactive command processing
  • Menu navigation and option selection
  • Modular design for extensibility
